Décisions prises

Hébergement

VPS Combell + Docker

Combell (belge, support 24/7 FR/NL, infra redondante, hébergeur Node.js reconnu) plutôt que Behostings — plus de marge et de support. Un VPS Linux (~4 Go RAM pour démarrer) fait tourner toute la pile via Docker Compose : API, site, PostgreSQL, reverse-proxy HTTPS, sauvegardes.

Portable — la pile Docker se déplace en une commande si tu changes d'hébergeur un jour.

Behostings resterait un choix valable : plus petit, un peu moins cher.

Migration

Machines + tarifs uniquement

On importe le catalogue (noms, photos, tarifs J/S/M, cautions — déjà récupérés depuis bricoloc.be et le PDF tarif). Pas de reprise des comptes clients : ré-inscription propre à la mise en ligne.

Paiement

Mollie (compte existant)

Bancontact + cartes, standard en Belgique, ~0,25 € + petit % par transaction, sans abonnement. Je branche la clé de test d'abord, la clé live au Lot 7. Le mode démo reste disponible pour les essais.

À me transmettre : la clé API de test depuis ton tableau de bord Mollie.

Navigation

Catégories + section chantier légère

Les 10 catégories réelles en navigation principale, plus une section « Pour quel chantier ? » sur l'accueil (6–8 tâches → sélection prête à l'emploi). Les BricoPacks complètent.

Scan

Zebra TC51, smartphone et scanner USB

Le mode Terminal fonctionne dans les trois cas : TC51 (scanner intégré, DataWedge), smartphone (scan par caméra, appli ou navigateur), poste fixe + scanner USB. Mêmes écrans partout : gros boutons, scan d'abord. Étiquettes QR + Code128 lisibles par tous.

Langues

Auto FR → NL/EN via DeepL

À chaque modification d'un texte en français (fiche produit, page, FAQ…), les versions NL et EN sont regénérées automatiquement via DeepL. Elles restent corrigeables à la main dans le back-office (un champ par langue). L'interface, elle, est traduite proprement.

À me transmettre : une clé API DeepL (l'offre gratuite — 500 000 caractères/mois — suffit pour démarrer).

Marque

Mascottes Brico / Bolt — plus tard

Elles n'existent pas encore. On démarre sans : la charte tient avec le logo « B », les photos, les vidéos et un jeu d'icônes. On les intègrera quand tu les feras produire.
